# Send to dot

[English](README.md) | **简体中文**

**从手机分享一张图片和可选问题，接回原来的 dot 对话。**

## 先让你自己的 dot 带着安装

把下面整段复制到你想继续使用的 dot 对话：

```text
请从下面的仓库选择最新发布的 Send to dot 版本，包括预览版，并告诉我选中了哪个版本。下载该版本，按包内的 INSTALL_FOR_DOT.md 带我安装，不要直接安装 main 分支。运行前先检查文件。使用我自己的 Mac、账号和服务，连接到当前对话。请自行完成能安全完成的步骤；必须由我登录、允许访问、选择费用或操作手机时，再让我接手。不要使用作者的账号、额度或凭据。

https://github.com/bryanzk/send-to-dot/releases
```

[打开已发布版本](https://github.com/bryanzk/send-to-dot/releases)。项目仍在测试，所以安装时也包括预览版。dot 必须核对哪个版本最近发布；GitHub 的“最新版本”入口可能不显示预览版。[版本选择说明](docs/LATEST_RELEASE.md)。

这不是一键无人值守安装。你的 dot 必须能操作你自己的 Mac。你仍需准备持续开机联网的 Mac 和固定安全网址，并亲自完成账号授权及手机步骤。

我做这个工具，是因为手机把图片分享给 ChatGPT 总会进入新聊天，还要切回原对话再传一次。Send to dot 只接收你主动分享的图片，不扫描相册；助手把原图作为附件发回原对话，不冒充你发送消息。

适用于已经能使用 dot、且能连接自建应用的 ChatGPT 用户。付费套餐本身不保证提供这些能力。

## 开始前准备

- 你的 dot 对话和 ChatGPT 账号。
- 一台持续开机联网的 Mac。
- Android 手机的 Chrome，或 iPhone 的「快捷指令」。
- 你自己的固定安全网址。
- 允许 dot 操作这台 Mac；或者请一位懂终端的人协助。

你承担自己的服务费用和账号用量。本项目不提供作者的主机或额度。核心服务不要求 OpenAI 模型 API key。

项目使用 MIT 许可证，版权署名为 bryanzk。正式仓库地址为 [bryanzk/send-to-dot](https://github.com/bryanzk/send-to-dot)。不得从来源不明的同名项目下载。

## 第一次使用：推荐 Mac 路线

### 1. 准备收件地址〔必须有技术协助〕

1. 在 Mac 下载正式仓库的源码或已核验的候选包并解压。
2. 请协助者按[部署指南](docs/QUICKSTART.md)启动服务。
3. 请协助者为服务配置固定安全网址。
4. 在手机浏览器打开这个网址。

**看到「发给 dot」页面，才继续下一步。** 打不开时，先请协助者修好。

下文用 `https://inbox.example.com` 举例。必须换成你自己的地址。不得使用作者的试用地址。

### 2. 在 ChatGPT 连接收件箱〔本人操作〕

1. 打开自己账号的自建应用创建页。入口找不到时，请协助者带你打开。
2. 在服务地址填写 `https://inbox.example.com/mcp`。
3. 将连接方式选为 OAuth，再发起连接。
4. 按[授权说明](docs/QUICKSTART.md#5-亲自完成-chatgpt-授权)，在自己的 Mac 终端取得 owner 授权码。
5. 核对授权页地址，再填写授权码。

owner 授权码只用于你自己的授权页。不得把它发送到聊天或群聊。账号密码由你本人保管。

**看到 ChatGPT 显示应用已连接，才继续。** 转圈或报错时，先看[故障说明](docs/TROUBLESHOOTING.md)，不得连续提交。

### 3. 指定原来的 dot 对话

1. 打开你希望继续使用的原 dot 对话。
2. 选择刚连接的收件箱应用。
3. 对助手说：

> 请把这个收件箱连接到当前对话。以后我主动分享的图片和问题，请在这里回应，并把原图作为附件发在这里。不要另开聊天。

**助手必须确认收件设置完成。** 这段话只表达你的意图，不会替代后台配置。

若助手无法完成，请协助者按[对话连接说明](docs/ATTACHMENT_AUTOMATION.md)设置。当前没有一键连接原对话的按钮。最后仍必须执行第 5 步。

### 4. 连接手机

#### Android

1. 用 Chrome 打开你的收件地址。
2. 在浏览器菜单安装 Send to dot。菜单名称因版本而异，通常是「安装应用」或「添加到主屏幕」。
3. 按[配对说明](docs/QUICKSTART.md#6-手机安装与配对)，在 Mac 取得手机专用上传码。
4. 将上传码填入手机页面的「手机连接码」。
5. 点「连接这台手机」。

**连接框收起，表示手机记住了码。** 在同一地址重开页面时，网站数据必须保留。上传码是否有效，由第 5 步确认。

#### iPhone

1. 打开本包的 `shortcuts/Send-to-dot.shortcut`。
2. 在「快捷指令」中添加它。
3. 配置地址 `https://inbox.example.com`。此处不加 `/mcp` 或 `/api/upload`。
4. 阅读保存说明；同意后，在第二个设置问题中本人填写手机专用上传码。

**在快捷指令列表找到 Send to dot，才继续。** 相册分享时按[iPhone 指南](docs/IOS_SETUP.md)运行它。

快捷指令首次配置地址和手机专用上传码，以后发送复用。码保存在私人快捷指令的可见文本中，可能随 iCloud 同步或导出。保存前必须了解并确认这个范围。不得分享填好码的副本，不得填写 owner 授权码或 OpenAI 密钥。

### 5. 用一张不私密的图片验证

1. 从你的地址下载 `/sample.png`。例如 `https://inbox.example.com/sample.png`。
2. 在相册选择这张样本，打开系统分享。
3. Android 选择 Send to dot；iPhone 选择 Send to dot。
4. 可以填写一句针对图片的问题，再发送。
5. 回到第 3 步的原 dot 对话。

**同时看到以下结果，才算接通：**

- 原对话收到针对该图片的回应。
- 填写的问题有对应回答。
- 原图作为助手附件出现在同一对话。

手机提示「已发送」只表示收件服务确认接收。它不能代替以上检查。只收到文字时，查看[附件排查](docs/TROUBLESHOOTING.md#助手看懂了图但聊天没有原图附件)。

完成样本检查后，再决定是否发送私人图片。

## 日常使用

**选一张图 → 可以写一句问题 → 发送 → 回原 dot 看回应。** Android 也可以在网页直接选图。

Android 成功发送后会清空当前图片。页面没有再编辑或重试按钮。网络出错时，先检查原 dot。刷新或重开不会自动重发。

**图片和回答会分两条出现：** 先发原图，随后回答问题。一次实测未达到 30 秒内显示图片的目标，目前不能保证这个速度。等待时不要连续重发。

## 能否只配置一次？

**目前不能永久免配置。** Android 保存同一地址的上传码。iPhone 快捷指令保存地址和上传码，不再逐次询问码。

新签发的上传和 ChatGPT 访问授权默认 30 天。旧连接仍按原期限到期；更新代码不会自动延长它们。到期必须正常续期或重新授权。重启电脑或重填旧码不会延长授权。

换手机、清除网站数据或换网址后，必须检查配对。授权撤销后，旧连接不再有效。详情见[配置和有效期](docs/CONFIGURATION.md)。

Mac 关机、睡眠或断网时不能收件。临时网址会失效，不适合作为长期地址。稳定服务和更省心的续期仍是产品缺口。

## 发送私人图片前

- 核对自己的收件地址。图片会经过你的服务和网络入口，再交给 ChatGPT。
- 原图可以包含拍摄信息。
- 收件箱保留图片和问题一小时。对话附件另行保存，必须另行删除。
- 每次只发一张 PNG/JPEG，最大 8 MB。不支持 HEIC、PDF、视频或自动同步相册。
- 手机只填写手机专用上传码。不得填写账号密码、owner 授权码、OpenAI 密钥或 Tunnel 密钥。

## 当前验证范围

一个真实用户环境完成了 Android 和 iPhone 图文分享、原 dot 读图及助手附件发送。新版 Android 页面完成了窄屏浏览器检查。

中文版快捷指令已有一次真实 iPhone 录屏发送；完整 30 天连续运行和真机多次发送免配置仍未验完。另一位已有 dot 的用户独立部署并完成全程，尚未验证。各设备的表现和长期运行也必须继续验证。

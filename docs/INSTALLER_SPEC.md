# Agent-guided installer acceptance

The user provides the official project link to their own dot. It checks source/environment, executes authorized reversible installation, and stops only for missing capabilities, user consent/login, resource/cost choices or phone actions. It never infers all dot users have local exec/browser/event/Library tools.

Unified CLI: node scripts/install.mjs plan|run|status|verify --origin HTTPS_ORIGIN. The plan is read-only and checks runtime/capability declarations. Run requires --approve-local plus --accept-access to initialize independent one-user24h credentials, preserving existing config and resuming through metadata checkpoints. It never purchases resources or silently generates long-term credentials. New dependencies from existing pinned registries are installed only with --install-deps. Existing same-origin config resumes; changed origin or unsafe/incomplete files stop with actionable recovery, never overwrite.

The CLI emits JSON only: stages/status/blocker/next-human-action, no secret values. Persistent checkpoint state is owner-only and atomic under state/installer.json. It is not an authentication receipt. Real browser OAuth/target-dot subscription/native attachment/phone results are not recorded as successful based on a flag. Capabilities are declared by the caller for planning only; the agent must actually discover its native tools and collect actual receipts. Generated fixture smoke is explicitly different from real platform acceptance.

Mac user service: node scripts/service.mjs plan|install|status|stop. Default plan read-only, no runtime config changes. install requires --approve-service, validates same-instance config, registers only a deterministic per-project user LaunchAgent. It refuses symlink/unknown existingplist, never overwrites unrelated jobs, never changes sleep/network/security settings. Uses exact Node/Python paths and configuration, shell-free argumentvector, own state logpaths. If its own job already exists, read actualstate before start; no blind duplicate. Stop targets only the exact instancejob. Fixed HTTPS ingress must be configured/owned by the user; verifier does anonymous origin/metadatachecks and does not configure DNS/Tunnel/proxy or purchase resources.

Verification: parser/flags/no-overwrite/origin mismatch/source-path safehandling/atomicresume redaction tests; service plan unsafeplistrejection/commandvector fixturetests with injected launchctl, no actual host registration. Fresh source package: isolated dependency install with disabledscripts, fixture setup/OAuth/SDK/upload/read smoke, independent securityreview. Never classify this as a second real user's dot/phone acceptance.

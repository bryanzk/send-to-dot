# Independent newcomer walkthrough

Review date: 2026-10-29. Read-only document and source walkthrough; no installation, service, network, UI, credentials, or phone tests were performed for this review. Existing test and trial claims below belong to the release documentation, not this review.

## Overall result

The candidate adequately states the BYO account/host/domain/credentials boundary, recommends stable HTTPS, and explains that the core public-HTTPS route does not require a model API key. It does not imply that ordinary ChatGPT eligibility follows from a paid plan. It remains a technical deployment candidate, rather than a complete low-friction daily-use product.

## Evidence boundaries to retain

- Account eligibility must be checked in the user's own account/workspace. This walkthrough did not independently verify current official platform policy or linked pages.
- Stable public HTTPS is the recommended route. Secure MCP Tunnel is optional and does not replace the phone website; its runtime credential requirements must not become an unnecessary default model API key prerequisite.
- HTTP readiness, OAuth success, event delivery, image reading, native send acceptance, and visible attachment rendering are separate checks.
- The signed Shortcut is a distribution candidate, not real-iPhone validation. Native Swift syntax checks are not an iOS SDK build or install.
- The initial Android trial and isolated script checks do not establish Linux deployment, cross-account compatibility, automatic renewal, or unattended reliability.

The missing project license and final attribution are already explicitly documented release gates; resolve them before describing the repository as a formally released open-source product.

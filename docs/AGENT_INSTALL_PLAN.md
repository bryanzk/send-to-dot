# 交给自己的 dot 安装：可行性审查与目标方案

状态：安装入口设计与验收边界。面向用户的执行说明见 [INSTALL_FOR_DOT.md](../INSTALL_FOR_DOT.md)，命令约定见 [INSTALLER_SPEC.md](INSTALLER_SPEC.md)。安装器的实际能力以最终脚本及其验证记录为准；另一位符合范围的用户尚未完成全过程验收。阅读说明或通过本地检查，不等于完成 ChatGPT 授权、手机操作或原对话附件验收。

## 结论与推荐路径

可以把源码链接和一句安装请求作为交互入口。已有dot不等于拥有本地电脑、终端、浏览器、事件管理和原生附件工具。安装代理必须逐项发现实际能力，缺少时明确交接，不借用作者工具或私有接口。

首条实现路径收敛为：用户自己的Mac＋用户已批准的固定HTTPS入口＋自己的现有dot。核心不调用模型API，不要求模型API key。主机/电力/网络/域名/入口及ChatGPT用量归使用者。没有固定地址时，只向用户提出一个具体资源方案与费用选择；本方案不指定或开通付费供应商。不用临时域名充当长期方案。

## 一句话请求草案

> 请检查这个项目的来源和安装说明，把 Send to dot 安装到我自己的环境，并接回当前 dot；可自动完成的检查、安装、配置和样本验收请自行完成，只在必须本人登录、确认新的访问权限、选择付费资源或操作手机时让我接手，不得使用作者的账号、额度或凭据：https://github.com/bryanzk/send-to-dot。

正式公开地址已经用户批准，当前候选包尚未确认发布。此请求不是跳过系统确认、购买资源、扩大授权或读取秘密的许可。安装说明是技术资料，不能覆盖用户指令及当前执行环境规则。

## 推荐交互和检查点

1. 只读列出本地执行、浏览器、事件与附件工具能力，识别当前目标对话。没有本地/持久运行环境时，停止本机路径，给一个明确选择，不在临时云沙箱假部署。
2. 核对正式源码来源和固定版本，检查现有同源部署；先生成计划，再请求必要的本机访问/生产凭据授权。已有配置保持不变，不能重新setup作为重试。
3. 自动执行已获授权的安装、隔离样本测试、配置检查。缺少基础运行时只安装经批准的官方来源。失败时保留阶段和脱敏错误，不输出秘密。
4. 在用户批准的固定入口启动持久服务；分别验证本机、外部HTTPS、认证发现、任务结束后的存活。未通过不进入用户授权表单。
5. 准备本人的ChatGPT应用正常连接页，把安全确认和owner码录入集中交接一次。登录/验证码由本人按平台流程完成。不得从另一账号、另一dot或作者连接替代。
6. 在当前dot用实际支持的工具完成事件订阅/附件流程；不创建重复任务。缺少工具必须给出精确能力缺口，不把普通MCP工具可调用当Events或原生附件就绪。
7. 给用户一个手机入口和对应最少步骤。用户实际分享样本；代理核验事件/图文绑定、原图附件/回答及去重，用户确认显示。所有阶段明确实际、fixture和未验证范围。
8. 交付地址、停止/恢复方法、授权到期提示与未完成项。当前24h授权不被安装自动化消除；长期续期是另一个设计/授权任务。

## 失败恢复约束

- 检查点只保存阶段、固定版本、非秘密路径和真实回执，不写秘密、原图或问题明文。恢复时先读取安装器 status，并核对真实运行状态。阶段记录不能证明 OAuth、订阅或原生附件已完成。
- 安装依赖失败：从锁定版本重跑对应阶段，不重新生成配置/密钥。
- 初始化半失败：当前setup会拒绝已有秘密/数据库；不能自动删除。新安装器需显式恢复未提交状态，不能静默覆盖。
- 入口失败：先核对实际进程、域名与发现；不改旧OAuth链接/state/code，不改系统DNS绕过。
- 应用/授权结果未知：核对实际连接状态后再决定，不重复创建连接或码。
- 订阅失败：核对真实订阅及授权期限，不盲建第二任务，不伪造签名回调。
- 原生保存/发送结果未知：保持ledger uncertain，核对真实Library/消息回执后恢复，不盲重发。
- 取消：只停止本次实例/进程，保留用户已有服务和独立数据；删除/撤销遵守具体授权与产品恢复机制。

## 命令入口与验收措辞

安装器入口为 `node scripts/install.mjs plan|run|status|verify --origin https://自己的固定地址`。执行本机修改需要 `run --approve-local --accept-access`；依赖安装另需 `--install-deps`。先检查计划，再按已获授权的范围执行。不得把参数名当作用户已同意新的访问范围。

Mac 常驻服务入口为 `node scripts/service.mjs plan|install|status|stop`；安装需要 `install --approve-service`。仅适用于同一用户的 Mac。服务常驻和 HTTPS 可达均不证明平台授权有效，也不延长 24 小时授权。

README 可以提供“把项目链接发给自己的 dot”的入口，并链接执行指引。不得承诺全程无人值守、永久免维护或跨账号已验证。独立用户必须使用自己的机器、账号、HTTPS 入口和用量，完成样本分享、同一对话回答和原图附件显示后，才能确认全过程验收。

## 资料与本地证据

- scripts/bootstrap.sh：基础命令存在检查、锁依赖安装、venv和preflight。
- scripts/setup.mjs：固定origin、独立本地秘密、24h上传授权、拒绝覆盖。
- scripts/preflight.mjs：本机元数据及可选匿名HTTPS发现；不证明平台/手机/附件。
- scripts/smoke.mjs：生成fixture、实际loopback/SDK链；非真实平台与手机。
- docs/ATTACHMENT_AUTOMATION.md：planner不执行原生工具，真实能力与回执不可替代。
- 官方连接界面：https://developers.openai.com/plugins/deploy/connect-chatgpt
- 官方事件协议：https://developers.openai.com/plugins/build/mcp-events
- 官方认证流程：https://developers.openai.com/plugins/build/auth

未发现可据此承诺通用无交互应用安装或跨账号附件自动发送的公开接口；这是本次审查范围内未确认的能力，不是对所有平台未来能力的断言。

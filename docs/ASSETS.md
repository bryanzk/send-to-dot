# Asset provenance

`web/sample.png` and the two app icons are generated geometric test/app graphics created for this project using local image tooling. They contain no user photographs, account data, image metadata copied from a camera, or third-party logos. They are included solely as nonprivate sample and interface assets. Project graphics are included under the project MIT license, Copyright (c)2026 bryanzk; their inclusion is not permission to publish the private working environment.

The Chinese v5 Shortcut is an Apple-signed blank template. Its address and upload code import fields are empty. `.actions.json` and unsigned candidates are source/test inputs, not configured personal copies. Do not publish a configured export. The English v5 candidate is not represented as signed or iPhone-tested.

The current release asset is `Send-to-dot.shortcut`, with signing input name Send to dot. `shortcuts/build_public_shortcut.py` reproduces its blank input. Apple signing must use that input; do not sign a personal configured export. Earlier version-named templates remain historical compatibility files, not the default public install target.

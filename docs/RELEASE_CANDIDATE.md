Source release for the existing Send to dot project. Installing or upgrading does not grant access, extend existing credentials or change a running deployment.

## Included content

- Public source/runtime and existing pinned dependency locks.
- Decoder startup verification and tests; no user JPEG fixture.
- Plain-language Android/iOS UI copy and signed blank Chinese v5 Shortcut. English v5 remains an unsigned source candidate; existing signed v4 remains available.

## Not included

Real photos or EXIF, screen recordings, owner/upload/read credentials, browser data, state/database/ledger/cache, private deployment address, personal machine paths, task transcripts, test probe or production backups.

Generated/isolated regression checks cover invalid image rejection and authorization. No private fixture is copied into source.

That does not prove repeated real-device no-prompt setup, every platform/version, or30-day continuity. A later Android-like upload after the runtime correction used different source bytes; its device provenance must not be inferred.

No stable latency claim is made. Another qualified dot user's independent installation is outstanding. Native iOS app source has not been signed/built/tested on an iPhone as a release product.
